# Security policy

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub: [Security › Report a vulnerability](https://github.com/moraliasp/jasao/security/advisories/new).

Include the Jasão version, your OS and, if possible, a file that reproduces the problem with anything private removed. We aim to reply within 7 days.

## Scope

Of particular interest: a JSON or JSONL file (plain or compressed) that crashes the app, runs script, makes it read or write files it wasn't given, loads remote content without the user asking, or exhausts memory or disk.
